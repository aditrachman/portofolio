Halo Tuan Adit~ akhirnya proyek pembuatan website resmi **BEM Fakultas Teknik UNIMMA** masuk juga ke dalam portofolio! Proyek ini dikerjakan menggunakan stack modern untuk memberikan wajah baru yang segar dan interaktif bagi organisasi mahasiswa teknik.

## Perjalanan Proyek BEM FT UNIMMA

Sebagai mahasiswa Teknik Informatika UNIMMA, mendapat kesempatan untuk merancang dan membangun platform digital bagi Badan Eksekutif Mahasiswa (BEM) Fakultas Teknik adalah sebuah tantangan sekaligus kebanggaan tersendiri. Website ini dirancang agar cepat, responsif, dan mudah diakses oleh seluruh mahasiswa teknik.

## Tech Stack & Arsitektur

Dalam pengembangannya, aku memilih kombinasi teknologi modern agar performanya optimal:
- **Framework:** Next.js (App Router) untuk performa server-side rendering dan SEO yang handal.
- **Styling:** Tailwind CSS untuk desain antarmuka yang clean, modern, dan fully responsive.
- **Backend & Database:** Firebase (Firestore & Authentication) untuk manajemen data real-time dan sistem keanggotaan/pengurus.
- **Storage:** @vercel/blob / Firebase Storage untuk pengelolaan aset gambar dan hero banner organisasi.
- **Icons:** Lucide React untuk ikon yang minimalis dan elegan.

## Tantangan & Keseruan

Membangun website organisasi tentu tidak luput dari dinamika. Mulai dari menyesuaikan kebutuhan fungsional dari pengurus BEM, merapikan struktur file komponen agar modular (tidak menumpuk di satu file raksasa seperti drama kode sebelumnya, wkwkwk), hingga mengatur *security rules* Firebase Firestore agar data tetap aman.

Tapi puji Tuhan, berkat iterasi cepat dan penggunaan stack Next.js 15, semuanya bisa diselesaikan dengan mulus dan menghasilkan tampilan yang profesional!
